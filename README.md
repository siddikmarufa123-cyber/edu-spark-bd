# EDU SPARK BD

**বাংলায় শেখো, আত্মবিশ্বাসের সঙ্গে এগিয়ে চলো।**

বাংলা-ফার্স্ট অনলাইন শিক্ষা প্ল্যাটফর্ম। প্রযুক্তি: **Next.js (React + TypeScript)**, **Supabase** (ডাটাবেস + লগইন), **Cloudflare Workers** (হোস্টিং), **GitHub** (সোর্স কোড)।

## এই প্রজেক্টে কী আছে

- বাংলা ডিফল্ট ওয়েবসাইট (Hind Siliguri ফন্ট) + বাংলা/English সুইচার
- হোমপেজ: ঘোষণা বার, হিরো, পরিসংখ্যান, শেখার পথ, SSC/HSC/কম্বো কোর্স, শেখানোর ধাপ, শিক্ষক, মতামত, FAQ, ফুটার
- কোর্স কার্ড (ছাড়ের ব্যাজসহ), কোর্সের বিস্তারিত পাতা, কোর্সে ভর্তির অনুরোধ
- শিক্ষার্থী রেজিস্ট্রেশন, লগইন, লগআউট, শিক্ষার্থী ড্যাশবোর্ড (আমার কোর্স)
- **সুপার অ্যাডমিন প্যানেল** (`/admin`): নাম, ট্যাগলাইন, রং, হিরো, ঘোষণা বার, সেকশন চালু/বন্ধ ও ক্রম, কনটেন্ট ব্লক, কোর্স যোগ/সম্পাদনা/মুছা, ফুটার তথ্য, রক্ষণাবেক্ষণ মোড, ভর্তি ও রেজিস্ট্রেশন চালু/বন্ধ
- **ড্রাফট → প্রিভিউ → প্রকাশ**, ড্রাফট বাতিল, ভার্সন হিস্ট্রি ও পুরনো ভার্সন ফিরিয়ে আনা
- API: `GET /api/courses`, `POST /api/enroll`, `GET /api/health`
- ডাটাবেস স্কিমা ও নিরাপত্তা নিয়ম (Row Level Security): `supabase/schema.sql`

## যা এখনো নেই (সৎভাবে জানিয়ে রাখছি)

পেজ বিল্ডার, ইমেজ/মিডিয়া লাইব্রেরি, SEO সেটিং প্যানেল, পপআপ, কাস্টম CSS/JS, পরীক্ষা সিস্টেম, লাইভ/রেকর্ডেড ক্লাস প্লেয়ার, স্টাডি ম্যাটেরিয়াল, ই-বুক, অনলাইন পেমেন্ট (বিকাশ/নগদ)। এগুলো পরের ধাপে যোগ করতে হবে।
ভর্তির অনুরোধ **"অপেক্ষমাণ"** অবস্থায় জমা হয়; পেমেন্ট যাচাই করে আপনি Supabase থেকে `status` কে `active` করবেন।

## ধাপ ১: Supabase সেট আপ (ডাটাবেস ও লগইন)

1. https://supabase.com এ গিয়ে ফ্রি অ্যাকাউন্ট খুলুন → **New project** → নাম দিন `edu-spark-bd`, একটি শক্তিশালী ডাটাবেস পাসওয়ার্ড দিন (কোথাও লিখে রাখুন, GitHub-এ দেবেন না), রিজিয়ন বেছে নিন।
2. প্রজেক্ট তৈরি হলে বাম মেনু থেকে **SQL Editor → New query** খুলুন।
3. এই প্রজেক্টের `supabase/schema.sql` ফাইলটি খুলে পুরোটা কপি করে পেস্ট করুন → **Run** চাপুন। "Success" দেখালে ডাটাবেস তৈরি।
4. **Project Settings → API** থেকে দুটি জিনিস কপি করে রাখুন:
   - **Project URL**
   - **anon public key** (`service_role` key কখনো ব্যবহার করবেন না)
5. **Authentication → Providers → Email**-এ গিয়ে শুরুতে **Confirm email** বন্ধ করুন (পরে চালু করতে চাইলে SMTP সেট করুন)।

## ধাপ ২: নিজের কম্পিউটারে চালিয়ে দেখা (ঐচ্ছিক)

1. Node.js (সংস্করণ ২০ বা নতুন) ইনস্টল করুন।
2. `.env.example` ফাইলের নাম বদলে `.env.local` করুন এবং Supabase-এর URL ও anon key বসান।
3. টার্মিনালে প্রজেক্ট ফোল্ডারে গিয়ে চালান:
```
npm install
npm run dev
```
4. ব্রাউজারে http://localhost:3000 খুলুন।

## ধাপ ৩: GitHub-এ আপলোড

**সহজ উপায় (ব্রাউজার দিয়ে):**
1. https://github.com এ অ্যাকাউন্ট খুলুন → উপরে **+ → New repository** → নাম `edu-spark-bd` → **Create repository**।
2. ZIP ফাইলটি **আনজিপ (Extract)** করুন। (ZIP ফাইল নিজে আপলোড করবেন না।)
3. রিপোর পাতায় **uploading an existing file** লিংকে ক্লিক করুন।
4. আনজিপ করা ফোল্ডারের **ভেতরের সব ফাইল ও ফোল্ডার** টেনে এনে ছেড়ে দিন (`src`, `public`, `supabase`, `package.json` ইত্যাদি)।
5. নিচে **Commit changes** চাপুন।

**টার্মিনাল দিয়ে (git ইনস্টল থাকলে):**
```
cd edu-spark-bd
git init
git add .
git commit -m "EDU SPARK BD first version"
git branch -M main
git remote add origin https://github.com/আপনার-ইউজারনেম/edu-spark-bd.git
git push -u origin main
```
`.gitignore` থাকায় গোপন ফাইল (`.env.local`) আপলোড হবে না।

## ধাপ ৪: Cloudflare Workers-এ ফ্রি পাবলিশ

1. https://dash.cloudflare.com এ ফ্রি অ্যাকাউন্ট খুলুন।
2. **Workers & Pages → Create → Import a repository** (GitHub সংযোগ দিয়ে `edu-spark-bd` রিপো বেছে নিন)।
3. বিল্ড সেটিংসে দিন:
   - **Build command:** `npx opennextjs-cloudflare build`
   - **Deploy command:** `npx wrangler deploy`
4. **Build variables** (এবং Variables) এ এই দুটি যোগ করুন:
   - `NEXT_PUBLIC_SUPABASE_URL` = আপনার Project URL
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = আপনার anon public key
5. **Save and Deploy** চাপুন। কয়েক মিনিট পরে `https://edu-spark-bd.আপনার-নাম.workers.dev` ঠিকানায় সাইট চালু হবে।
6. Supabase-এ ফিরে **Authentication → URL Configuration**-এ **Site URL**-এ এই workers.dev ঠিকানা দিন।

(Cloudflare ড্যাশবোর্ডের বাটনের নাম সময়ের সাথে একটু বদলাতে পারে।)

কমান্ড লাইন থেকে ডিপ্লয় করতে চাইলে: `npx wrangler login` তারপর `npm run deploy`।

## ধাপ ৫: নিজেকে Super Admin বানানো

1. পাবলিশ করা সাইটে গিয়ে নিজের ইমেইল দিয়ে **রেজিস্ট্রেশন** করুন।
2. Supabase → **SQL Editor** এ নিচের লাইনটি (নিজের ইমেইল বসিয়ে) চালান:
```sql
update public.profiles set role = 'super_admin'
where id = (select id from auth.users where email = 'আপনার-ইমেইল@example.com');
```
3. সাইটে আবার লগইন করুন। হেডারে **সুপার অ্যাডমিন** বাটন দেখা যাবে।
4. অ্যাডমিন প্যানেলে পরিবর্তন করুন → **লাইভ প্রিভিউ** দেখুন → **প্রকাশ করো** চাপুন।

## নিরাপত্তার নোট

- এই প্রজেক্টে কোনো গোপন কী বা পাসওয়ার্ড নেই। শুধু Supabase-এর পাবলিক anon key লাগে, যা ব্রাউজারে দেখা যাওয়াই স্বাভাবিক।
- ডাটা সুরক্ষা হয় `schema.sql`-এর Row Level Security নিয়ম দিয়ে: শিক্ষার্থী শুধু নিজের ভর্তির তথ্য দেখে, শুধু Super Admin সাইট বদলাতে পারে।
- `service_role` key কখনো GitHub বা ফ্রন্টএন্ডে দেবেন না।
- সম্পূর্ণ নিরাপত্তা পরীক্ষা (সঠিক RLS আচরণ, অনুমতি ছাড়া লেখা ব্লক হচ্ছে কি না) সাইট চালুর আগে নিজে বা কোনো ডেভেলপার দিয়ে যাচাই করে নিন।

## ফোল্ডার কাঠামো

```
src/app/(site)     পাবলিক পাতা (হোম, কোর্স, কোর্সের বিস্তারিত)
src/app/(auth)     লগইন, রেজিস্ট্রেশন, শিক্ষার্থী ড্যাশবোর্ড
src/app/admin      সুপার অ্যাডমিন প্যানেল
src/app/api        API রুট
src/components     হেডার, ফুটার, কোর্স কার্ড, হোম ভিউ
src/lib            Supabase সংযোগ, সাইট সেটিংস, ভাষা অনুবাদ
supabase/schema.sql ডাটাবেস স্কিমা, নিরাপত্তা নিয়ম, নমুনা তথ্য
wrangler.jsonc, open-next.config.ts  Cloudflare কনফিগ
```

## সমস্যা হলে

- **সাইটে "Supabase" সংক্রান্ত এরর:** ধাপ ৪-এর Build variables ঠিক আছে কি না দেখুন, তারপর আবার ডিপ্লয় করুন (ভ্যারিয়েবল বিল্ডের সময় দরকার)।
- **কিছুদিন পর সাইটে তথ্য আসছে না:** Supabase ফ্রি প্রজেক্ট পজ হয়ে থাকতে পারে — ড্যাশবোর্ডে গিয়ে Restore করুন।
- **ডিপ্লয় সাইজ এরর:** Cloudflare ফ্রি সীমা ছাড়িয়েছে — প্ল্যান বিষয়ে Cloudflare ডকুমেন্টেশন দেখুন।
